# Two skeletons, one task

Pre-generated results for the "One Task, Two Skeletons" exercise from
Day 1 morning.

- `src/a.rs`: Skeleton A, completed the way an agent typically completes
  it. Every test passes. Read the test names: each one shows a
  defect that the skeleton allowed.
- `src/b.rs`: Skeleton B, completed. The commented-out lines in its
  tests are the calls that no longer compile, with the compiler errors
  they produce.

Run `cargo test` to see module `a`'s defects pass as living
documentation.
