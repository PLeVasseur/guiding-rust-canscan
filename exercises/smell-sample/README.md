# Smell exercise sample

About 150 lines of generated Rust. It compiles without warnings and its
test passes. Every problem in it gets past the compiler, which is why it's
 a review exercise.

In pairs, 8 minutes: produce one row per finding (smell with line
references, principle violated, the prompt that fixes it), working in
triage order rather than file order. At least one construct that looks
like a smell is a legitimate use; find it and write down why it stays.
